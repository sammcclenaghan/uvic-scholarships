# UVic Scholarships

Search 1,300+ University of Victoria undergraduate and graduate scholarships and awards.

Award data comes from UVic's scholarship listings — the extraction scripts in `scripts/` pull the raw API responses into `data/`, and the site searches over them.

## Stack

- Next.js + React
- Tailwind CSS

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```
